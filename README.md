<h1 align="center">Sortable</h1>

<p align="center">This web application lets you organize and search for information on superheroes using a JSON database. It offers the following features:
Customized display: Users can choose the information to be displayed (name, power, etc.) and customize the column order.
Advanced search: A search bar lets users filter results by superhero name.
Pagination: Search results are paginated for easier readability.
Sorting: Data can be sorted alphabetically or numerically in any column.</p>

## Install
```
git clone <repository-url>
```
