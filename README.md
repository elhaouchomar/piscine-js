# Sortable

<p align="center">This project is an interactive web application that displays a table of superhero data. It allows users to view, search, sort and page through a large collection of information on various superheroes</p>

## Install
```
git clone <repository-url>
```

## Fonctionnality  

- Tabular display of required superhero data
- Real-time, interactive superhero search by superhero.
- Sort superhero information by clicking on any column (e.g. name, weight...). Sort in ascending alphabetical or numerical order.
- Superhero icon display
- Pagination with option to select number of elements per page.

## Usage

- The table loads automatically with superhero data.
- Use the search bar to filter superheroes by name.
- Click on the column headers to sort the data.
- Use the drop-down menu at the top of the page to change the number of items displayed per page.
- Navigate between pages using the pagination buttons at the bottom of the table.
